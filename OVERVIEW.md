# Conductor — Overview

## What it is

A personal productivity operating system built for engineers juggling multiple concurrent W2 roles. Conductor replaces tools like Things 3 and adds AI-powered meeting prep, follow-up tracking, transcript processing, communication drafting, and persistent per-role conversations — all in one app you actually own.

It is **single-user by design**. One person. One password. No accounts, no teams, no SaaS. The data lives in your Postgres, the files live on your disk, the AI calls go directly to Anthropic with your key.

## The problem it solves

When you run multiple roles in parallel — a CTO at one company, a director at another, an advisor on a third, plus side projects — context switching is the bottleneck. Generic task managers don't understand that "Standup prep" for Role A is irrelevant during Role B's time block. Calendar apps don't generate prep notes. Note apps don't surface what to bring up next week. Slack threads die in noise.

Conductor wires those signals together and surfaces only what matters for the role you're currently working in.

## Who it's for

- Engineers managing 3+ concurrent roles where context switching is a tax
- People who use AI heavily and want it grounded in their actual work, not a generic chatbot
- Anyone who finds typical productivity apps too noisy (badge counts, "completed" sections, end-of-day guilt screens)
- Neurodivergent users who need a quiet, focused interface that doesn't generate anxiety

## Core features

**Focus mode.** The current time block determines which role you're in. Conductor shows tasks and follow-ups for that role only. When the role has no tasks, a priority waterfall pulls from the highest-priority role with work pending.

**Tasks.** A flat task list per role with tags, priorities, due dates, source attribution, and an attached files drawer. Completed tasks slide out and are gone — no "completed" view, no count.

**Follow-ups (Tracker).** Tracked separately from tasks. The only proactive nudge in the app: stale follow-ups surface when waiting too long.

**Board.** Kanban view per role (Backlog / In Progress / In Review / Done) with show/hide done toggle.

**AI Chat.** Persistent thread per role, plus per-meeting and per-task scoped threads. Slash commands (`/standup-prep`, `/draft-update`, `/meeting-prep`, etc.) resolve role-aware templates. The AI can return rendered artifacts (HTML, React, Mermaid diagrams) sandboxed in iframes.

**Meeting drawer.** For every meeting on your calendar, a drawer with five tabs: AI Prep (context-aware notes generated by Haiku), Notes, Transcript (from Granola), AI Chat (scoped to the meeting), Tasks (action items), Files (drag-and-drop attachments).

**Documents.** Centralized file library with previews for text, markdown, PDFs, and Word docs.

**Drafts.** AI-generated message drafts in your voice, ready to copy into Slack/Teams/email.

**Morning Briefing.** A short markdown brief generated each morning summarizing the day across all your roles.

**Global search.** Cmd+K across tasks, follow-ups, notes, transcripts, drafts, and conversations.

## Integrations

| Source | What it does | Cadence |
|---|---|---|
| **macOS Calendar** (EventKit) | Reads events directly from Calendar.app, generates prep tasks, maps calendar accounts → roles | Hourly on the hour, 7 AM – 4 PM weekdays via LaunchAgent |
| **Linear** | Syncs assigned issues into tasks, mapped per-role with status tracking | Hourly via cron sidecar |
| **Granola** | Pulls meeting transcripts, extracts action items + follow-ups + decisions via AI | Every 30 min via cron sidecar |

All three use a `sourceType + sourceId` dedup pattern so re-syncs are idempotent.

## AI architecture

Every Claude API call assembles a 5-layer context (~10K tokens max):

1. **System prompt** — roles, schedule, waterfall, artifact instructions
2. **Voice profile** — your communication style and sample messages
3. **State snapshot** — today's tasks, active follow-ups, current time block
4. **Role context** — the current role's tone, responsibilities, goals, staff, recent notes/transcripts
5. **Retrieved context** — keyword-matched notes and transcript summaries on demand

Model selector lets you switch between Sonnet 4.6 (default), Haiku 4.5 (cheap), and Opus 4.6 (deep work) per request. AI usage and costs are tracked per role.

## Design philosophy

These rules are non-negotiable in the codebase — every PR enforces them:

1. **No badge counts anywhere.** Numbers create anxiety.
2. **Completed tasks are gone.** Slide-out animation, removed from DOM. No "completed" view.
3. **Follow-ups are not tasks.** Different rhythm, different view, never mixed.
4. **Focus mode shows one role.** No cross-role noise.
5. **Morning task selection is optional.** Skip straight to focus.
6. **End of day is silent.** Incomplete tasks quietly return to backlog. No summary, no guilt.
7. **Stale follow-ups are the only proactive alert.** Everything else waits for you to look.

## Tech stack

- **Next.js 14** (App Router) + React + TypeScript
- **PostgreSQL 16** via Prisma ORM (16 models)
- **Tailwind** + **shadcn/ui** + **Framer Motion** + **Lucide**
- **NextAuth** (credentials provider, single-user)
- **Anthropic Claude API**
- File processing via `pdf-parse`, `mammoth`, `sharp`
- **Docker** for the app + sidecar; LaunchAgents on macOS for calendar/sync
- Optional **AWS CDK** stack for EC2 deployment
